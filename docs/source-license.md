`vendor/psprecomp/` contains the pinned MIT-licensed upstream source plus local
runtime/discovery changes. Its original copyright and MIT grant are retained in
`vendor/psprecomp/LICENSE`. `SOURCE_MANIFEST.json` records the exact exported
patched sources. `patches/prototype-runtime.patch` and
`patches/strict-executable-analysis.patch` document changes to the donor; the
included donor is already patched and must not have those patches applied again.

Adapted service code in `src/asphalt_mpeg.c`, `src/asphalt_atrac.c` and
`src/savedata.c` retains the MIT attribution in `THIRD_PARTY_LICENSES.txt`.
No additional project-wide copyright grant is asserted by this export.

FFmpeg 7.1.4 is fetched from its official release URL with the exact checksum.
The local builds enable only the required H.264, ATRAC3, ATRAC3plus and scaling
components and do not enable GPL or nonfree options. Keep the matching FFmpeg
source, configuration and LGPL notices with any distributed binary, following
the Windows packaging instructions. Toolchain binaries are not in source.

`metadata/psp-import-names.json` contains PSP ABI function names keyed by NID for
diagnostics. The ISO parser derives the imported NIDs and libraries afresh from
the user's BOOT; this table supplies names only.

The application icon in public source is an original geometric placeholder
generated by `tools/export_source.py`; the controls are user-supplied artwork.
The `screenshots/` folder contains user-supplied gameplay captures for preview;
rights in the depicted game remain with their owners.

game code, firmware or any other third-party game asset.
